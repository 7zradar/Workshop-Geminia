# Especificar

Lee specs/workshop.md y la spec relacionada. Escribe objetivo, usuario, entradas, salidas, límites y tabla de criterios con ID, acción y resultado observable. Para el agente define las dos herramientas y qué evidencia debe conservar. Para el flujo define disparador, segundo agente, errores y repetición. Para la página usa el contrato real de salida/ultimo.json.

Aclara las decisiones que afectan el alcance y registra las asumidas. Termina con la spec lista para revisar y una propuesta de tareas verificables. Mantén las expectativas de pruebas independientes de lo que produzca el modelo.
