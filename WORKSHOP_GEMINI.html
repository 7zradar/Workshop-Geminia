Antes de empezar

Descarga el repositorio completo y extrae el ZIP. Necesitas Antigravity con sesión iniciada, Python 3.12 y Node 22+. Si faltan Python o Node, el preparador indica qué instalar con TI. No necesitas Git si descargaste el ZIP.

El facilitador entrega el motor, las pruebas, las skills y la infraestructura. El equipo construye los agentes y la página. 

powershell -NoProfile -File .\preparar-workshop.ps1

Ejecuta ese único comando en PowerShell, dentro del repositorio, antes del taller. Crea la práctica, prepara .venv, instala las dependencias y comprueba tres skills y las pruebas locales. El kit nuevo debe mostrar 2/4 y 50 % por el bug preparado. Si se interrumpe, repite el mismo comando: conserva tu trabajo.

Al ver PREPARACION COMPLETA, abre practica/equipo-01 en Antigravity y sigue los prompts. Los agentes y la página los construirás tú. La API key se configura una sola vez, después de construir el primer agente y antes de ejecutarlo con Gemini. No actives el entorno manualmente: los comandos cortos taller.ps1 lo usan por ti.

La preparación instala paquetes Python y necesita conexión. Si TI restringe scripts o descargas, comparte el mensaje con TI. Para la demostración del facilitador usa .\iniciar.ps1. Specs, skills y vibe coding se aplican desde el módulo 1.
